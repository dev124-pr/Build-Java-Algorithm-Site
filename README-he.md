# CodeDrop — אתר פרטי לקובצי Java

אתר סטטי בעברית עם שני עמודים: **הקבצים שלי** ו־**הורדות**. משתמש יכול להירשם, להעלות קובצי `.java` עד 10 MB, לחפש ולמיין את הקבצים שלו, לפתוח, להוריד או למחוק אותם. עמוד ההורדות מוכן; הוספת כתובת לקובץ ההתקנה תפעיל את כפתור ההורדה.

## איך זה עובד

- **Supabase Auth** מנהל חשבונות והתחברות.
- **Supabase Database** שומר פרטי קובץ (שם, בעלים, נתיב וגודל).
- **Supabase Storage** שומר את תוכן הקובץ בתוך bucket פרטי.
- מדיניות RLS ב־`supabase-setup.sql` מגבילה את רשומות הקבצים ואת האובייקטים באחסון למשתמש שבבעלותו. הקובץ הפרטי נפתח באמצעות קישור חתום וקצר־תוקף.

האתר לא שומר חשבונות או קבצים במחשב של המבקרים. צריך פרויקט Supabase כדי שההרשמה, ההעלאה והפעולות על הקבצים יעבדו. אפשר לפתוח את עמודי האתר גם לפני החיבור.

## חיבור Supabase

1. צרו פרויקט ב־[supabase.com](https://supabase.com) ושמרו את כתובת הפרויקט ואת ה־**publishable/anon key**.
2. בדשבורד של הפרויקט, פתחו **SQL Editor** והריצו את כל התוכן של `supabase-setup.sql`. הסקריפט יוצר טבלת `java_files`, מפעיל עליה RLS, יוצר bucket פרטי בשם `java-files` ומגדיר מדיניות בעלות.
3. פתחו את `config.js` והחליפו את `YOUR-PROJECT` ואת `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` בערכים מהדשבורד (Project Settings → API).
4. ב־Supabase פתחו **Authentication → URL Configuration** והגדירו את כתובת האתר שתפרסמו כ־Site URL. הוסיפו אותה גם ל־Redirect URLs. בפיתוח מקומי הוסיפו `http://localhost:8000/**`.
5. פתחו דרך שרת מקומי (לא `file://`). מתוך התיקייה `java-vault` אפשר להריץ:

   ```powershell
   python -m http.server 8000
   ```

   ואז פתחו `http://localhost:8000`. אפשר לפרוס את התיקייה כמו שהיא ב־Netlify, Vercel או אירוח סטטי אחר, ולהוסיף את כתובת הפריסה ל־URL Configuration.

6. הירשמו באתר. אם אימות מייל מופעל בפרויקט, אשרו את המייל ואז התחברו.

### אבטחת מפתחות

מותר לשים ב־`config.js` רק את כתובת הפרויקט ואת ה־**publishable/anon key**. הוא מיועד לשימוש בדפדפן, כאשר RLS פעיל. לעולם אל תכניסו לכאן `service_role` או מפתח סודי אחר — המבקרים יכולים לקרוא את קובצי האתר ולחלץ כל ערך מתוכם.

### הוספת קובץ התוכנה לעמוד Download

העלו את קובץ ההתקנה לשירות אחסון/הפצה ציבורי שאתם סומכים עליו, והגדירו ב־`config.js`:

```js
downloadUrl: "https://your-domain.example/CodeDropSetup.exe",
downloadLabel: "Windows · קובץ התקנה"
```

כשהכתובת לא ריקה, הכפתור בעמוד **הורדות** יהפוך לכפתור הורדה פעיל. אין צורך להעלות את קובץ ההתקנה ל־Supabase של קובצי המשתמשים.

## מה המשתמשים יכולים לעשות

- להעלות קובצי `.java` בלבד עד 10 MB.
- לצפות רק בקבצים ששייכים לחשבון המחובר, לפתוח אותם בקישור חתום, להוריד ולמחוק.
- למצוא קובץ בחיפוש או למיין לפי תאריך, שם וגודל.

הממשק בעברית. הקוד בקבצים `app.js` ו־`styles.css`; עיצוב האתר מותאם גם למסכים קטנים.
