# JavaDesk — אפליקציית Java מקומית

JavaDesk היא אבטיפוס של סביבת עבודה שולחנית שנכתבה כולה ב־Java עם Swing. היא לא קשורה לאתר, ל־Supabase או למסד נתונים. הפרויקטים של המשתמש נשמרים בתיקיות מקומיות שהוא בוחר.

## הפעלה

1. פתח ב־IntelliJ IDEA את התיקייה `JavaDeskIDE`.
2. ודא שמוגדר לפרויקט JDK מלא (נדרש `javac`, לא JRE בלבד).
3. פתח את `JavaDeskIDE.java` והרץ את `main`.

## שימוש

- **פרויקט חדש** יוצר תיקייה מקומית עם תיקיית `src`.
- **פתיחת פרויקט** מאפשרת לפתוח תיקייה קיימת.
- **הוספת קובץ Java** מעתיקה קובץ `.java` לתיקייה שנבחרה בסייר הפרויקט.
- **תיקייה חדשה** יוצרת תיקייה בתוך הפרויקט.
- קבצים תחת `templates` מוצגים לקריאה בלבד ומשתתפים בקומפילציה. הקובץ `templates/GameMain.java` הוא נקודת הכניסה המובנית.
- כפתור ההרצה מקמפל את קובצי ה־Java בפרויקט וב־`templates`, ואז מפעיל רק את `GameMain`. אפשר גם ללחוץ F5.
- אפשר לערוך ולשמור רק קובצי Java שהוספו לפרויקט. קובצי `templates` נעולים לעריכה בממשק.

כדי להוסיף קובצי תבנית משלך, שים אותם בתוך `templates` ליד `JavaDeskIDE.java`. האפליקציה מציגה אותם לקריאה בלבד. כדי לשנות תוכן של תבנית, ערוך אותה כמפתח לפני הפצת האפליקציה.

## מבנה התחלתי

```text
JavaDeskIDE/
├── JavaDeskIDE.java
├── README-he.md
└── templates/
    └── GameMain.java
```

זוהי גרסת בסיס: היא כוללת סייר פרויקט, עורך Java פשוט, שמירה, הוספת קבצים, קומפילציה והרצה של `GameMain`. היא עדיין לא כוללת השלמת קוד, ניהול חבילות מתקדם או מתקין להפצה.
